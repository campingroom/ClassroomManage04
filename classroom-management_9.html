รายชื่อนักเรียน

📋 วิธีเชื่อมต่อ Google Sheets (ทำครั้งเดียว ใช้ได้ตลอด)

  1. เปิด Google Sheets → สร้าง Spreadsheet ใหม่ ตั้งชื่อว่า Classroom DB
  2. คัดลอก Sheet ID จาก URL: docs.google.com/spreadsheets/d/[ID อยู่ตรงนี้]/edit
  3. ไปที่เมนู Extensions → Apps Script วางโค้ดจากไฟล์ Code.gs ที่ดาวน์โหลดไว้
  4. วาง Sheet ID ลงในตัวแปร const SHEET_ID = '...' ในโค้ด
  5. กด Run → initSheets() เพื่อสร้าง Sheets อัตโนมัติ (อนุมัติ permission)
  6. กด Deploy → New deployment → Web App
    ตั้งค่า: Execute as = Me | Who has access = Anyone
  7. คัดลอก Web App URL ที่ได้ มาวางในช่อง "ตั้งค่า Sheets URL" ในโปรแกรมนี้
💡 ดาวน์โหลดไฟล์ Code.gs ได้จากลิงก์ที่ได้รับ หรือขอใหม่จาก Claude
